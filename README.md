# Obsidian Project Automation

Плагин Obsidian для задач и проектов. Задача - отдельная заметка со свойствами, работа по ней пишется в ежедневных
заметках, а плагин собирает эти записи в заметке задачи. Кроме этого в плагине доска задач, напоминания, блокнот
для быстрых записей, активности и игровой прогресс.

## Установка

```bash
npm install
npm run build
npm run install-plugin -- <путь к хранилищу>
```

`build` собирает `main.js` и `styles.css`. `install-plugin` копирует их вместе с `manifest.json` и `defaults.json`
в `.obsidian/plugins/obsidian-project-automation` хранилища. Затем включите плагин в Settings → Community plugins.
Доска задач, напоминания, блокнот, активности и геймификация включены по умолчанию, в настройках плагина их можно
выключить.

`npm run verify` перед выкладкой проверяет типы, запускает тесты и собирает плагин. `npm run test:dom` ставит jsdom
и запускает тесты вместе с DOM-тестами.

## Как устроено

- Задача - заметка, у которой во frontmatter есть `status`, `project` или `group`. Команда «Создать задачу» создаёт
  её в корне хранилища. Заметки из `templates/` и `Archive/` на доску задач не попадают.
- Работа по задаче пишется в ежедневной заметке `periodic/daily/ДД-ММ-ГГГГ.md` под заголовком со ссылкой на задачу,
  например `### [[Задача]]`. Блок `opa-task-view` в заметке задачи показывает все такие записи по датам.
- Проект - заметка, у которой `project` совпадает с именем файла. Блок `opa-project-view` в ней показывает задачи,
  у которых в `project` записано имя этой заметки.
- Домашняя страница `Homepage.md` собирает остальные блоки. Команда «Открыть или создать домашнюю страницу»
  создаёт её с доской задач, проектами, напоминаниями, блокнотом, корзиной, активностями и прогрессом.

## Блоки

| Блок | Что показывает |
| --- | --- |
| `opa-home-view` | Доска задач: все задачи по статусам, статус меняется прямо в таблице |
| `opa-projects-view` | Список проектов, первыми идут проекты с большим числом задач |
| `opa-project-view` | Задачи проекта по группам (`group`) |
| `opa-task-view` | Записи о задаче из ежедневных заметок |
| `opa-reminders-view` | Напоминания |
| `opa-inbox-view` | Блокнот |
| `opa-task-inbox`, `opa-project-inbox` | Записи блокнота, привязанные к задаче или проекту. Эти блоки плагин вставляет сам |
| `opa-trash-view` | Корзина: удалённые записи блокнота и напоминания, кнопка «Очистить» |
| `opa-activities-view` | Активности |
| `opa-gamification-view` | Прогресс: уровень, XP, Gold, магазин |
| `opa-daily-nav` | Ссылки на предыдущий и следующий день в ежедневной заметке |

## Задачи

Статусы задач: «В работе», «Тестирование», «Повторяющиеся», «Backlog», «Готово», «Отменено». Доска показывает
у задачи контекст, проект, окружение, статус, дедлайн и срок работы по датам записей. Статус меняется выпадающим
списком, а комментарий к смене статуса плагин записывает в «Описание задачи».

Форма «Создать задачу» спрашивает шаблон, название, проект, контекст, окружение, дату задачи, сложность, статус,
группу, дедлайн и дату ежедневной заметки. Сложность есть в форме, когда включена геймификация, дедлайн - когда он
включён в настройках. Плагин создаёт заметку по шаблону, открывает её и добавляет `### [[Задача]]` в ежедневную
заметку выбранного дня («-» - не добавлять). Если указан дедлайн, появляется напоминание «Дедлайн по задаче: …»
за заданное в настройках число дней.

«Создать задачу из текущей строки» берёт название из строки под курсором или из выделения. В ежедневной заметке
после создания задачи эта строка становится заголовком `### [[Задача]]`.

«Запись о задаче» в заметке задачи спрашивает день (по умолчанию сегодня), при необходимости создаёт ежедневную
заметку, добавляет в неё заголовок задачи и ставит курсор в его секцию.

В блоке `opa-task-view`:

- записи идут по датам, сверху «Оглавление» по подзаголовкам записей, а если подзаголовков нет - по датам;
- записи и «Оглавление» сворачиваются;
- в меню правой кнопки мыши есть «Копировать», у картинки ещё «Копировать изображение»;
- «Изменить» в том же меню правит запись прямо в блоке и сохраняет её в ежедневную заметку;
- Ctrl+C копирует выделенное как markdown исходной ежедневной заметки, а не как текст превью;
- ширина картинки меняется перетаскиванием её правого края;
- Ctrl+F в режиме редактирования ищет и по записям блока.

Значения свойства `project` в панели свойств ведут в заметку проекта, если у свойства тип «Список». Клик открывает
её в той же вкладке, Ctrl/Cmd+клик - в новой, Ctrl/Cmd при наведении показывает предпросмотр. Команда
«Открыть проект задачи» делает то же с клавиатуры, а если проектов несколько, предлагает выбрать.

«Создать проект» создаёт заметку проекта по шаблону и добавляет проект в список проектов для формы задачи.

## Блокнот

Команда «Запись в блокнот» и карандаш на ленте открывают окно записи поверх любой заметки. Выделенный текст сразу
попадает в поле, Enter переносит строку, Ctrl/Cmd+Enter сохраняет. Несохранённый текст остаётся черновиком
до следующего открытия окна.

- Запись - markdown: многострочный текст, ссылки, картинки. Скриншот из буфера сохраняется вложением.
- Поле «Относится к» привязывает запись к задаче или проекту. В окне туда сразу подставляется открытая задача
  или проект, а в ежедневной заметке - задача из заголовка, под которым стоит курсор.
- Под записью видно, когда она сделана и к чему относится. Записи с одной привязкой собираются в группу.
- Записи задачи видны и в её заметке (блок `opa-task-inbox`), записи проекта и его задач - в заметке проекта
  (блок `opa-project-inbox`).
- Кнопки у записи: «Архив» (в архив блокнота), «Задача» (новая задача из записи, с проектом из привязки),
  «Напоминание», «Изменить», «Удалить» (в корзину).

## Напоминания

Напоминание - строка `- [ ] текст (@ДД-ММ-ГГГГ ЧЧ:ММ)` в любой заметке, кроме шаблонов. Время можно опустить
(тогда 10:00), дату можно писать и как `ГГГГ-ММ-ДД`. Повтор задаётся так: `(every 2 weeks)`, единицы - day, week,
month, year. Напоминания из блока и из команды «Новое напоминание» плагин хранит в `data.json`.

Блок `opa-reminders-view` раскладывает напоминания по разделам «Просрочено», «Сегодня», «Завтра», «Предстоящие»
и «Архив». Новое напоминание добавляется полем вверху блока, галочка отмечает выполненное, у напоминания есть
«Изменить» и «Удалить» (в корзину). В срок плагин показывает окно с кнопками «Выполнено», «Отложить на 1 час»,
«Отложить на завтра» и «Выбрать дату...». Когда повторяющееся напоминание выполнено, появляется следующее.

## Активности и прогресс

В `opa-activities-view` - дела без напоминаний. В блоке отмечают, что сделано за день, а «Статистика» показывает
по месяцам, когда что делалось.

`opa-gamification-view` показывает уровень, XP и Gold. Их начисляют за задачу, переведённую на доске в «Готово»
(или созданную сразу готовой), за отмеченную активность, за напоминание, выполненное в блоке или в окне
напоминания, и за «Архив» в блокноте. Награда за задачу и активность зависит от сложности. Gold тратится
в магазине, лоты настраиваются в «Управление». «Выполненные» и «Стрики» показывают историю задач и серии
повторяющихся напоминаний.

## Панель «Структура»

Показывает заголовки заметки, как Outline, а ещё пункты «Оглавления» записей задачи и заголовки блоков плагина.
Клик по пункту прокручивает заметку к нему, Ctrl/Cmd+клик по записи открывает её ежедневную заметку. Панель
встаёт рядом с Outline, открыть её снова можно командой «Открыть панель «Структура»».

## Команды

- «Создать задачу»
- «Создать задачу из текущей строки»
- «Запись о задаче» (в заметке задачи)
- «Открыть проект задачи» (в заметке с проектом)
- «Создать проект»
- «Открыть или создать ежедневную заметку»
- «Открыть или создать домашнюю страницу»
- «Открыть панель «Структура»»
- «Запись в блокнот»
- «Новое напоминание»

Горячих клавиш по умолчанию нет, их можно назначить в Settings → Hotkeys.

## Настройки

Контексты и окружения для формы задачи, пример шаблона задачи, дедлайн и напоминание о нём, комментарий при смене
статуса, включение модулей, награды геймификации и автообновление доски («Refresh»).

## Шаблоны и данные

- `templates/task.md` - шаблон обычной задачи. Каждый файл `templates/task-templates/*.md` - отдельный тип задачи
  в форме, `opa_project` и `opa_group` в нём задают проект и группу. Текст шаблона после `<!-- opa:daily -->`
  в задачу не попадает.
- `templates/project.md` и `templates/daily.md` - шаблоны проекта и ежедневной заметки. Если файла нет, плагин
  берёт встроенный шаблон. Новую пустую ежедневную заметку в `periodic/daily/` плагин заполняет по шаблону сам.
- В шаблоне задачи работают `%%project%%`, `%%context%%`, `%%environment%%`, `%%date%%`, `%%difficulty%%`,
  `%%group%%` и `%%deadline%%`, в шаблоне проекта - `%%projectName%%`, в ежедневном - `%%daily_nav%%` (ссылки
  на соседние дни).
- Блокнот, напоминания из блока, активности, корзина, список проектов и прогресс лежат в `data.json` плагина.
  `defaults.json` задаёт начальные контексты, окружения, проекты и лоты магазина.
